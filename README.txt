Persönlicher Kalorien-, Gewichts- & Fitnesstracker

Diese Version kann von mehreren Personen benutzt werden:
- Jede Person öffnet dieselbe Web-App auf ihrem eigenen Gerät.
- Beim ersten Start wird ein eigenes Profil mit Alter, Geschlecht, Größe, Gewicht, Aktivität und Ziel eingerichtet.
- Kalorien- und Proteinziele werden grob berechnet.
- Alle Daten bleiben lokal auf dem jeweiligen Gerät.
- Ernährung, Gewicht, Fitness, Favoriten und 7-Tage-Übersicht sind getrennt je Gerät.

Installation auf iPhone:
1. Dateien auf GitHub Pages veröffentlichen.
2. URL in Safari öffnen.
3. Teilen -> Zum Home-Bildschirm.
4. Profil einrichten.

Hinweis:
Die berechneten Kalorien- und Proteinziele sind Schätzwerte und ersetzen keine medizinische Beratung.
